# ✦ DormGlow — Hostel Room Makeover & Glow-Up Studio

> **Transform your standard 10×10 ft. hostel room into a cozy, aesthetic sanctuary on a student budget.**

DormGlow is a modern, responsive, and interactive web application tailored for college and hostel students. It provides budget-conscious decor ideas, modular storage hacks, DIY weekend crafts, and smart planning tools without requiring drilling, painting, or heavy investments.

---

## ✨ Features

- **🛏️ 12 Curated Room Makeovers**: Filter by *Small Room*, *Budget Decor*, *DIY Ideas*, *Gaming Setup*, *Aesthetic*, and *Study Corner*. Interactive 3D flip cards with photography, estimated budgets, difficulty levels, and quick setup tips.
- **✨ Room Glow-Up (Before & After Slider)**: Draggable comparison slider to visualize bleak hostel rooms transforming into warm aesthetic havens (mouse, touch, and keyboard support).
- **🎯 Find My Room Vibe Quiz**: 4-step personalization quiz matching users to the best room makeovers based on style, space, budget, and priorities.
- **💰 Smart Budget Planner**: Dynamic budget allocation across bedding, lighting, decor, storage, desk, and plants. Includes preset challenges (₹500, ₹1,000, ₹3,000) and room-size adjustments.
- **🛒 My Shopping List**: Organize decor items, track purchases, compute pending spend, and receive budget overrun alerts.
- **♥ Dream Board (Moodboard)**: Save favorite ideas, view combined estimated budget ranges, and export/print the board cleanly.
- **🔨 DIY Idea Generator**: 20 actionable student hacks with difficulty ratings (Beginner, Intermediate, Advanced), step-by-step instructions, and safety notes.
- **🔍 Discovery & Practical Filters**: Search by keyword, sort by budget/difficulty/name, and filter by tags like *Renter-Friendly*, *No-Drill*, *No-Paint*, and *Small Space*.
- **💾 Local Storage Persistence**: Saves your dream board (`dg_saved`), shopping checklist (`dg_shopping_list`), recently viewed ideas, and makeover progress locally.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or serve it locally using Python:

```bash
# Start local HTTP server
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser.
